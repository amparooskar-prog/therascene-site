# TheraScene the SPED Center site

A responsive, static site for TheraScene the SPED Center, based on its public Facebook page.

The homepage links to dedicated overview pages for occupational therapy, speech therapy, special education, and academic tutorials. Program descriptions explain general areas of support and prompt families to confirm TheraScene's specific availability, session details, and goals directly with the center.

All pages share the same responsive header and Programs dropdown. On desktop, Programs opens on hover and remains available by click; on smaller screens, it opens from the menu button. Each page ends with a blue contact footer and consistent Messenger, Viber, and phone buttons.

The homepage footer also includes the center's email and address. Program pages use the same blue footer treatment with their topic-specific contact prompt.

## Preview

Open `index.html` in a browser. The site has no build step or external dependencies beyond the optional Google Fonts import; local images are included in `assets/`.

## Page source

The logo and event photos in `assets/` were captured from public images shown on the TheraScene the SPED Center Facebook page. The page links back to Facebook for current updates. Contact details and listed offerings reflect information visible on the page when this site was created.
